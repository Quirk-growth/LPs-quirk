# LPs — Quirk Growth

Repositório único das landing pages menores da Quirk (Growth, Clinics, Social Media, etc.).
Cada pasta é uma LP independente. Projetos maiores ou com lógica própria têm repositório separado.

## Índice

| Pasta | LP | Observações |
|---|---|---|
| `iscas/` | Isca KPI + GPA | Form nativo (não Typeform). Cenário Make 4755230. |
| `tech/` | Quirk Tech | Rebrand dark premium da LP principal. Assets pesados de mídia. |
| `auto-ads/` | Quirk Auto Ads | LP do produto de automação de anúncios. |
| `nau-marina/` | Nau Marina | LP de empreendimento. |

## Repositórios relacionados (fora daqui)

- **Calculadora VGV** → `Calculadora-vgv-quirk` (tem motor de cálculo, por isso é separada)
- **Quirk Auto Ads (automação)** → `quirk-auto-ads`
- **Área de membros** → `area-membros-quirk`

## Como adicionar uma LP nova

1. Crie uma pasta aqui dentro (ex.: `nova-lp/`)
2. Coloque os arquivos da LP
3. Nunca versione: `.env`, `node_modules/`, chaves de API (já bloqueados no `.gitignore`)
